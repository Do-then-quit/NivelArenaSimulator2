# Open Questions

## 룰/UX 미해결 항목
- 효과 배치 예외를 `PLAY` 그룹 안의 별도 배지로 둘지, 별도 `SYSTEM`/`INTERACTION` 그룹으로 분리할지 최종 결정이 필요하다.
- 블록 페이즈에서 가디언 인접 가능 레인을 보드 강조로 충분히 표현할지, 별도 레인 연결선 UI가 필요한지 판단이 필요하다.
- audit trail의 기본 fallback를 `대기 상태`로 둘지, 최근 legal action 요약으로 바꿀지 결정이 필요하다.
- end phase hand adjustment에서 선택 진행률을 상단 queue와 오른쪽 action panel 중 어디에 우선 표기할지 추가 UX 결정이 필요하다.
