# Rules Snapshot

## 핵심 진행 구조
- 턴은 `레벨업 -> 드로우 -> 메인 -> 어택 -> 엔드` 순서로 진행한다.
- 어택 구간은 최소한 `공격 선언 -> 방어 선언 -> 전투/대미지 -> 전투 종료`로 읽혀야 한다.

## 핵심 존
- 레벨 존
- 대미지 존
- 유닛 존 3개
- 스킬 존
- 덱 존
- 트래시 존

## 필수 룰 축
- 현재 사이즈는 기본적으로 `리더 레벨 + 대미지 수`로 계산한다.
- 유닛 존과 스킬 존의 총 코스트는 현재 사이즈를 넘길 수 없다.
- 일반 배치/업그레이드는 같은 유닛 존에서 턴당 1회 제한이다.
- 효과로 유닛을 배치하는 경우에는 위 제한과 분리된 예외로 다룬다.
- 엔트리는 선택이 아니라 강제 처리다.
- 액티브는 유닛당 턴 1회 상태를 보여줘야 한다.
- 가디언은 인접 레인 기준으로만 성립한다.
- 덱 0장은 즉시 패배가 아니지만, 0장 상태에서 드로우 요구가 발생하면 패배한다.

## UX에 직접 연결되는 룰 표현
- 가능 행동은 숨기지 말고, 불가능한 행동도 이유와 함께 보여준다.
- 강제 효과는 팝업보다 해결 대기열 최상단 우선이다.
- 로그는 결과보다 `행동 / 원인 / 타이밍`을 같이 남긴다.
