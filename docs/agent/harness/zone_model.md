# Zone Model

## 공개/비공개
- 덱: 수량만 공개
- 손패: 소유자 기준 공개 여부가 달라질 수 있음
- 유닛 존: 항상 공개
- 스킬 존: 항상 공개
- 대미지 존: 공개 카드 스택으로 취급
- 트래시: 항상 공개

## 유닛 존
- 3개 레인을 고정 인덱스로 다룬다.
- 레인 인접성은 `0 <-> 1 <-> 2`만 허용한다.
- lane 기반 룰은 UI에서도 같은 인덱스를 사용한다.

## 코스트/사이즈
- 필드 코스트는 유닛 존 + 장착 아이템 + 스킬 존 합산 기준이다.
- 일반 배치, 업그레이드, 스킬 사용은 모두 사이즈 제한 설명이 필요하다.
- 효과 배치는 별도 출처 배지로 구분해 normal deploy와 합치지 않는다.

## 표현 원칙
- 유닛 존 강조는 엔진의 `visibleActions` 또는 타겟 후보 데이터만 근거로 한다.
- 보드는 공식 영역 구도를 유지한다.
- 가디언/방어는 인접 관계가 시각적으로 드러나야 한다.
